THE WHOLE DAY DAILY — a one-image broadsheet summing up Monday 23 November 2026: 40 stories across 7 regions on a single 1024x1024 front page (white paper, dark-brown ink, gold accents). Lead story: a 7-year-old boy pulled alive from the rubble in Kyiv, six killed. Twelve numbered main cards with certainty chips and sources, a THE DAY IN NUMBERS box, a dotted world map with numbered pins, a UTC timeline, a red DATE CHECK box of stories that were NOT from 23 November, and 28 further numbered stories in ALSO ON MONDAY.

## Run it

```sh
python3 main.py
```

Copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`) after verifying its size and SHA-256. Standard library only.
